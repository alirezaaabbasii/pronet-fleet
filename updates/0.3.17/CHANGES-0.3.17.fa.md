# 0.3.17

حافظهٔ آماری مستقل و محدود به ۲ مگابایت روی هماهنگ‌کننده، با خلاصهٔ کیفیت حامل و بدون تست یا ارسال آمار پس‌زمینه. اولویت‌بندی حامل‌های موفق و کنار گذاشتن حامل‌های ضعیف پس از شواهد کافی در مسیرها و روزهای متعدد؛ حفاظت در برابر تکرار یک تست، خطاهای نصب، قطعی کامل مسیر و تغییر نسخهٔ موتور.

نمایش گزینهٔ ۱ برای تست پیشرفته فقط پس از شکست کیفیت همهٔ گزینه‌های عادی و تأیید پاک‌سازی. درخواست صریح کاربر، جفت‌سازی تازه به همان خارجِ قبلاً تأییدشده می‌سازد و همهٔ حامل‌های پیاده‌شده از جمله کنارگذاشته‌ها و اضطراری‌های دارای پیش‌نیاز را بدون محدودیت حافظه بررسی می‌کند. تونل فعال دیگری متوقف نمی‌شود و join دوباره لازم نیست.

دستورهای memory، memory clear و pair --full-test؛ افزودن این کنترل‌ها به منو. آزمون‌های آماری مستقل از تست واقعی شبکه و تست کامل شکست عادی -> تأیید صریح -> تست پیشرفته در لینوکس.

رفع بارگذاری مجدد ناخواستهٔ Backhaul هنگام نوشتن دوبارهٔ تنظیمات یکسان؛ این اتفاق وسط آزمون طولانی و تکرار start باعث قطع اتصال می‌شد. تنظیمات بدون تغییر دیگر بازنویسی نمی‌شوند. اثر تغییر آداپتور و آزمون کیفیت نیز در اعتبار نسخهٔ آمار لحاظ می‌شود.
