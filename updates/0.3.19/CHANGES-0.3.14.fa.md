# Pronet Fleet 0.3.14

- GRE مستقیم لینوکس با نام مستقل `gre` به تست‌های پیش‌فرض اضافه شد؛ از BackPack استفاده نمی‌کند.
- همان تست‌های اتصال، رفت‌وبرگشت، سلامت داده، half-close، سرعت و بیکاری را می‌گذراند و سپس می‌تواند اصلی یا پشتیبان شود.
- خانوادهٔ مستقل GRE در انتخاب پشتیبان، و مجوز فایروال IP protocol 47 فقط برای دو IP همین جفت.
- ساخت رابط با پروندهٔ مالکیت ثبت می‌شود؛ روی کرنل‌هایی که alias را هنگام ساخت اعمال نمی‌کنند، برچسب با SETLINK تکمیل می‌شود؛ رابط بیگانه یا رابطی که endpoints/key آن عوض شده باشد، تصاحب یا حذف نمی‌شود.
- پاک‌سازی عادی و ExecStopPost پس از مرگ پردازش، رابط متعلق به همین تونل را حذف می‌کنند. route پیش‌فرض و sysctl عمومی تغییر نمی‌کند.
- GRE به /dev/net/tun و دانلود باینری BackPack نیاز ندارد؛ پورت عمومی TCP ترجیحیِ حامل‌های دیگر را هم مصرف نمی‌کند.
- GRE رمزنگاری یا احراز هویت ندارد؛ key فقط شناسهٔ جداسازی است. کار کردن آن روی مسیر واقعی ایران/خارج تنها با اجرای تست روی همان مسیر معلوم می‌شود.

این تغییر همهٔ ابزارهای موجود در research/catalog را به حامل فعال تبدیل نمی‌کند. فهرست README و `pronet profiles` پوشش اجرایی واقعی را نشان می‌دهد.
