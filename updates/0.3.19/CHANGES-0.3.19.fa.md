# نسخهٔ 0.3.19

اگر حامل اصلی پس از فعال‌سازی دائمی تست را رد کند، پشتیبان‌های قبول‌شده به ترتیب بررسی می‌شوند. مسیر خراب از هر دو سرور کنار گذاشته می‌شود و پورت کاربران فقط پس از قبولی دوباره باز می‌شود. خطای مالکیت، توقف نامطمئن یا قطع ارتباط مدیریتی همچنان نصب را متوقف می‌کند.

مرحلهٔ خطا و نتیجهٔ بررسی هر حامل پس از نصب نگهداری می‌شود. پیام تداخل GRE، subnet و مسیر متداخل و رابط مربوط را مشخص می‌کند؛ مسیر سرویس‌های دیگر تغییر نمی‌کند.

حامل‌ها، معیارهای سخت‌گیرانهٔ گیمینگ و تنظیمات سرویس‌های فعال تغییر نکرده‌اند.
