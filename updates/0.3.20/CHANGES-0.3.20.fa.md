# نسخهٔ 0.3.20 — چند IP روی یک سرور ایران

برای هر تونل جدید، IP ایران جداگانه انتخاب می‌شود. چند IP متفاوت می‌توانند هم‌زمان پورت کلاینت یکسان، مثلاً 2053، داشته باشند و به سرورهای خارج متفاوت وصل شوند. پورت‌های داخلی حامل‌ها همچنان جدا تخصیص داده می‌شوند.

در منوی ساخت Standard یا Gaming، ابتدا IP همین تونل را انتخاب کنید و سپس پورت را بدهید. در خط فرمان: `sudo pronet pair --public-ip IP --port 2053`؛ برای WireGuard گزینهٔ `--gaming` را هم اضافه کنید. برای NAT از `--bind-ip LOCAL_IP` استفاده کنید.

ثبت IP جدید هویت قبلی سرور و آدرس هماهنگ‌کننده را تغییر نمی‌دهد و سرویس‌های تونل فعلی را ری‌استارت نمی‌کند. حافظهٔ کیفیت مسیرها برای هر IP مستقل است. IP باید روی سرور تنظیم شده باشد و از داخل همان سرور تأیید شود.

آپدیت با همان دستور نصب انجام می‌شود؛ منابع متعلق به تونل‌های موجود حفظ می‌شوند. فقط سرویس‌های مدیریتی هنگام فعال‌سازی نسخهٔ جدید ری‌استارت می‌شوند؛ حامل‌ها و درگاه‌های فعال ادامه می‌دهند. نصب مجدد یا uninstall لازم نیست.
